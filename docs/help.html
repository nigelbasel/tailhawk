Getting started

Open a log with Ctrl+O, or drop a file on the window. Tailhawk does not read the whole file to show it to you, so a multi-gigabyte log opens as fast as a small one.

If the file is still being written, Tailhawk follows it. Scroll up and following pauses so the view stays where you put it; Ctrl+End jumps back to the tail and resumes. The right-hand end of the status bar always says which of the two you are in.

You can also pipe into it:

some-command | tailhawk -

Opening files and remote sources

Files

File > Open (Ctrl+O) opens one log. The bottom of the File menu lists the logs you opened recently. Tailhawk detects the text encoding itself — UTF-8, UTF-16, and the Windows code pages — and the status bar names what it decided.

A log that rotates is followed across the rotation: when the writer starts a new file, Tailhawk keeps reading, and the older parts stay in the scrollback.

Remote sources

The cloud button on the toolbar, and Tools > Remote sources, open a Loki source. Pick the labels you want and Tailhawk tails the result in the same window as a local file — the same search, the same filters, the same columns.

Watch the right-hand end of the status bar. A remote tail says how far behind it is — ● Following · current to 30s ago. A source that has gone quiet and one Tailhawk cannot keep up with look identical without it.

Loki returns at most a fixed number of records per query and does not say when it stopped at that limit. When Tailhawk sees a full answer it tells you, and every count taken over that window is shown as a floor — at least 47 matches, not 47 matches — because there may be records it was never sent.

The gutter

The numbers down the left are physical line numbers — where the line is in the file, not where it is in the view. They do not renumber when a filter hides rows, so a number you read here is the number you can go to with Ctrl+G. Bookmarks and severity marks appear in the same column.

Finding

Ctrl+F opens Find. F3 steps to the next match, Shift+F3 to the previous, and Esc clears the search.

The search runs on a worker, so a large file stays responsive while it works; the Find pane on the status bar counts matches as they are found and says so far until the pass finishes.

Finding does not hide anything. To hide the lines you are not interested in, filter.

Filtering

A filter hides rows in place. The rows are still in the file, the line numbers still say where they are, and clearing the filter brings them straight back.

  • Ctrl+L adds an include: keep only lines matching this.
  • Ctrl+Shift+L adds an exclude: drop lines matching this.
  • Esc clears them all.

Filters stack, and the filter panel — the funnel on the toolbar — lists them, lets you edit and reorder them, and tick them off one at a time. Right-clicking a line offers Filter to this text and Filter out this text, which is usually quicker than typing.

Collapsing continuation lines

Many logs write one record across several physical lines: the first carries the timestamp and the message, and the lines under it are the stack trace, or a pretty-printed body. Those extra lines are continuations.

Collapse continuation lines hides them, so a forty-line stack trace becomes the one line that says what failed. It has no effect on a log where no format was detected, because without a format there is no way to tell a continuation from a record.

Traces

Services that carry a trace or correlation id put the same id on every line belonging to one request, across every service it touched.

Put the cursor on a line and press Ctrl+T, or use the Trace button, and Tailhawk takes the id on that line and filters the view down to it. What you are left with is that one request, in order, from wherever it went. If the line carries no id, nothing happens.

It is an ordinary filter once applied, so Esc clears it.

Columns and formats

Tailhawk reads the head of a file, recognises the shape of the lines, and splits them into aligned columns — a timestamp column, a level column, a message column, and whatever else the format carries. The Format pane on the status bar names what it decided.

The raw line is never modified. Searching, filtering and Ctrl+C all work on the text as it is in the file, whatever the columns are doing.

Why some columns start hidden

A JSON log invents a column for every key it carries. Telemetry records routinely carry a dozen — trace ids, span ids, pod names, namespaces — around one message, and showing all of them pushes the message off the right-hand edge where it cannot be read.

So for a format derived from a file's own keys, Tailhawk starts by showing the timestamp, the level and the message, and hides the rest. The View pane on the status bar says how many are hidden — 3 of 9 columns — and Format > Select columns ticks any of them back on.

Fitting the window

Whatever columns are shown, the message keeps room. Wide columns are trimmed before narrow ones, so a four-character level column is never squeezed to pay for a sixty-character trace id, and if the window is too narrow to hold them all, the ones furthest right are hidden rather than everything being shaved to nothing. Widen the window and they come back.

Drag a column's edge to resize it, double-click the edge to reset that one, and Format > Reset columns restores the lot. A width you set deliberately is kept — resizing the window will not take it back.

When nothing is detected

If Tailhawk does not recognise the format, it shows the lines as they are written, which is always correct and never wrong — just not aligned. Format > Define format from a line lets you point at a line and describe its shape, and what you define is remembered for next time.

Highlight rules

Ctrl+K, or the highlighter button, opens the rules. A rule is a pattern and a colour: lines that match are drawn in it, so the thing you are hunting stands out while you scroll past everything else.

Rules apply to every log you open, not just this one. A rule that will not compile is reported on the status bar by name rather than being dropped quietly.

Under Windows High Contrast, highlight rules are switched off and the status bar says so. High Contrast exists so that the system's colours are the only ones on screen; a viewer that painted its own over them would defeat it.

Exporting and tailing to a file

File > Export writes what you can see — the rows the current filters kept, in the current order — to a file. It is the quickest way to hand someone the fifty lines that matter instead of the whole log.

A live tee keeps writing as the log grows, so you can start one on a filtered view and leave it running. Either way the Message pane counts the lines as they are written, and says when it has finished or why it could not.

Settings

Tools > Options holds the preferences; Tools > Font picks the face and size the log is drawn in. View > Toolbar hides the toolbar or switches it to large icons.

Tailhawk follows the Windows light and dark setting, and switches with it while it is running. Each file's view — its column widths, its filters, where you were — is remembered and restored when you open it again.

Troubleshooting

The messages are off the right-hand side

This was a defect in builds before 21 September 2026, on logs whose records carry many fields. It is fixed: the message column now keeps room whatever else is shown. If you still see it, Format > Reset columns restores the default layout.

Columns I want are missing

For JSON logs, Tailhawk starts with timestamp, level and message and hides the rest — see Columns and formats. The View pane on the status bar says how many are hidden. Format > Select columns ticks them back on, and a column you tick on stays on.

The window is not updating

Check the right-hand end of the status bar. If it says ‖ Paused you have scrolled up and following has stopped; Ctrl+End resumes. If it says Stream complete, the thing writing to the pipe has finished.

A remote tail looks stale

The Tail pane states the lag. If it keeps growing, Tailhawk is not keeping up with the source or the source is not receiving; if it stops changing, the source has gone quiet. The two look the same without the lag, which is why it is stated rather than implied.

Counts say "at least"

The remote query came back full, which means it stopped at its limit and there may be records you were never sent. Narrow the time range or the selector and the counts become exact.

The icons look wrong, or the buttons are words

Tailhawk draws its toolbar from the Windows icon font. If that font is missing, or is missing one of the symbols, it falls back to labelled buttons rather than drawing empty boxes.
